Q1: Tăng Trưởng Game Phát Hành & Mô Hình Free-to-Play
0.45s Impala SQL Q1

Bảng: games_parquet (Phân vùng theo release_year) Quét HDFS: 32.5 MB (Snappy Columnar) Tối ưu hóa: Partition Pruning (2000-2025) 
SELECT release_year, COUNT(*) AS total_games,
       COUNT(CASE WHEN is_free THEN 1 END) AS free_games,
       ROUND(COUNT(CASE WHEN is_free THEN 1 END) * 100.0 / COUNT(*), 2) AS free_ratio_pct
FROM games_parquet
WHERE release_year >= 2000 AND release_year <= 2025
GROUP BY release_year ORDER BY release_year;
Insight: Giai đoạn 2014-2024 chứng kiến sự bùng nổ theo cấp số nhân (đạt đỉnh 18,282 game năm 2024). Tỷ lệ game Free-to-Play tăng đều từ 4% (2009) lên 17.26% (2024).
Q2: Tốc Độ Tăng Trưởng Hàng Năm (YoY Growth %)
0.48s Impala SQL Q2

Kỹ thuật: Hàm cửa sổ LAG() OVER () Tốc độ: 0.48s (Tính toán MPP) 
WITH yearly AS (
    SELECT release_year, COUNT(*) AS cnt FROM games_parquet
    WHERE release_year >= 2005 GROUP BY release_year
)
SELECT release_year, cnt,
       ROUND((cnt - LAG(cnt, 1) OVER (ORDER BY release_year)) * 100.0 / 
             NULLIF(LAG(cnt, 1) OVER (ORDER BY release_year), 0), 2) AS yoy_pct
FROM yearly;
Insight: Cột mốc năm 2014 bùng nổ tăng trưởng 231.5% nhờ việc Valve đơn giản hoá quy trình đưa game lên Steam (Greenlight).
Q3: Sự Tiến Hóa Thể Loại Qua 4 Kỷ Nguyên Steam (JOIN Phân Tán)
0.82s Impala SQL Q3

Phép JOIN: games_parquet (Fact) JOIN games_genres (Dim) Chiến lược JOIN: Broadcast Join sau COMPUTE STATS 
SELECT CASE 
         WHEN g.release_year < 2010 THEN '1. Cổ điển (2000-2009)'
         WHEN g.release_year BETWEEN 2010 AND 2014 THEN '2. Greenlight (2010-2014)'
         WHEN g.release_year BETWEEN 2015 AND 2019 THEN '3. Bùng nổ Indie (2015-2019)'
         ELSE '4. Hiện đại (2020-2025)' END AS period_era,
       gg.genre, COUNT(*) AS total_games
FROM games_parquet g JOIN games_genres gg ON g.appid = gg.appid
GROUP BY 1, 2 ORDER BY 1, total_games DESC;
Insight: Thể loại Indie từ vị trí khiêm tốn ở kỷ nguyên Cổ điển đã vươn lên chiếm đa số áp đảo ở kỷ nguyên Hiện đại với hơn 42,000 tựa game.

Q9: Khám Phá Game Dị Biệt (Outlier Analysis)
0.75s Impala SQL Q9

Công thức: Z-Score = (reviews - AVG) / STDDEV Thời gian thực thi: 0.75s trên toàn bộ 89K dòng 
WITH stats AS (
    SELECT AVG(num_reviews_total) AS avg_rev, STDDEV(num_reviews_total) AS std_rev FROM games_parquet
)
SELECT name, price, num_reviews_total,
       ROUND((num_reviews_total - s.avg_rev) / s.std_rev, 2) AS z_reviews
FROM games_parquet CROSS JOIN stats s
WHERE price = 0.0 AND (num_reviews_total - s.avg_rev) / s.std_rev > 3.0
ORDER BY num_reviews_total DESC LIMIT 20;
Insight: Trực quan hoá sự tương phản rõ rệt: Các tựa game miễn phí (CS2, Dota 2, PUBG) thu hút hàng triệu review, đối nghịch với các game bán $200 - $999.98 hầu như không ai tương tác.
